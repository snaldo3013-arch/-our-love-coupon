사랑 쿠폰북 7.0 — QR 초대장 + 두 휴대폰 동기화 (설정 필요)

1) Firebase Console에서 프로젝트 생성 → Authentication → 익명(Anonymous) 로그인 활성화.
2) Firestore Database 생성 후 firestore.rules 내용을 보안 규칙으로 게시.
3) Firebase 웹 앱 등록 후 firebase-config.js의 FILL_ME 항목을 실제 구성값으로 교체.
4) 이 폴더의 파일을 모두 Netlify에 업로드(HTTPS).
5) 본인 폰에서 앱을 열고 '새 코드 만들기' → '두 휴대폰 연결하기'.
6) 'QR 초대장 만들기 / 인쇄' 버튼으로 종이 초대장을 인쇄.
7) 여자친구가 QR을 스캔하면 같은 쿠폰북이 열림. Android Chrome의 앱 설치/홈 화면에 추가로 설치.

중요: QR 스캔만으로 APK가 자동 다운로드/설치되는 것은 아닙니다. 사용자가 브라우저 설치를 선택해야 합니다.
QR에 포함된 코드는 접속 권한과 같으므로 공개 공유하지 마세요. 클라이언트 PIN은 실제 관리자 보안이 아닙니다.
동시 구매/출석 시 충돌 가능성이 있어 금융성 포인트 운영에는 서버 트랜잭션과 권한 분리가 필요합니다.
배경 사진은 개인정보와 저장용량 때문에 기기별 로컬에만 보관됩니다.
외부 QR 라이브러리 및 Firebase SDK는 인터넷 연결이 필요합니다.
